# RCI Engineering website

Preview of the new rcieng.com, built by Bizsual.

## What is here today

- `index.html`: the locked signature hero for the main page (approved by Jose Perdomo III on October 19, 2026). It is a single static page with no build step.
- `vercel.json`: tells search engines not to index this preview.

## Deployment

- Every push to `main` deploys to Vercel automatically.
- This project lives on its own Vercel address. It is not connected to rcieng.com. The live domain keeps serving the coming soon page until launch.
- The production site will be rebuilt in Next.js at the build stage. This page is the approved reference for the hero.

## Accounts

GitHub, Vercel and Resend are owned by the RCI project login. Nothing is under a Bizsual or personal account.
